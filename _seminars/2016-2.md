  - date: 2016-12-09
    time: 14:00–15:30
    speaker: Gemayqzel Bouza Allende
    affiliation: Facultad de Matemática y Computación, Universidad de La Habana
    joint: J.Y. Bello and Ch. Tammer
    title: Line search algorithms for computing minimal points of variable order optimization problems
    abstract: |
      Let K : R^n ⇒ R^n be a cone-valued mapping, C a convex set, and F a smooth function. A point x^∗ ∈ C is a minimizer of the function F in C with respect to the ordering given by K if there is no other x ∈ C such that F(x^∗)−F(x) ∈ K(x^∗). This model appears in economic and in medical practical problems, see [1, 3, 6].

      Characterizations of minimal points and related classes of points, as well as algorithms for computing them, can be found in [2]. As in vector optimization, an important role is played by scalarizing functions, i.e. real- valued functions whose zeros are closely related with the set of minimizers. In this work, we will present the steepest descent algorithm based on scalarizing functions. Two particular cases are analyzed.
